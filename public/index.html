How Nexora handles models honestly

  • Models are labeled runs locally or requires internet — accurately.
  • Nexora never calls a model “free” unless its provider documents a free tier, and never bypasses rate or usage limits.
  • API keys are stored on the local server only (config/settings.json) — never in front-end files, browser storage, or logs. The API never sends a stored key back to the page.
  • Rate limits, quotas, and outages are reported with the actual provider error and a concrete fix.
  • Failed requests keep your message so you can retry without retyping.

Security

  • API keys are stored server-side (config or environment variables) — never in front-end files.
  • The browser can only reach this local server; provider traffic is proxied through it.
  • API endpoints are rate-limited and responses are validated.
  • Logs are kept free of secrets.
  • Studio project access is read-only until you approve changes.

About

NEXORA AI

An AI development assistant for Roblox: describe what you want, Nexora plans it, and applies approved changes through a real Studio integration.

This build implements Stage 2 (AI Connection) — the interface, local server, and real AI chat through configured providers. Projects persistence arrives in Stage 3; the Studio connection in Stage 4. Nothing in the chat is simulated — every assistant reply comes from the model your active provider returns.
